# 按键开启网络配置

复用上下键可切到、底部已有「长按 OK 配置」提示的设备页。保留设备编号、时间和可用空间，并在这页显示 Wi-Fi 与配置蓝牙的实时状态。Wi-Fi 已连接时显示当前实际关联的 SSID，例如「Wi-Fi 已连接 · STEPX Neo」。断开时显示「未连接」或「正在连接」，清除上一条已连接的 SSID。配置蓝牙显示「关闭」「等待连接」或「已连接」。页底提示「长按 OK 启用蓝牙配置」。配置蓝牙等待连接或已连接时，改为提示「长按 OK 取消」。再次长按关闭配置蓝牙并恢复 Wi-Fi。已进入提交或试连的事务仍按原规则处理。

只有设备空闲且当前显示配置页时，长按 OK 才能开启一次配置会话。普通录音页保留短按录音、录音中长按保存。未配置设备从同一页面进入首次配网，已配置设备进入换网。配置页使用简短状态提示显示正在连接、切换成功、失败已恢复或超时。

取消周期蓝牙窗口。设备平时维持 Wi-Fi 连接和上传。进入配置时让上传暂停并保留进度。已配置设备开启换网蓝牙后，等待连接和对端断开均不关闭广播。用户在配置页再次长按 OK 主动关闭，开始录音也可抢占无线资源。首次配网仍沿用有时限的配对码。已经持久化的换网操作按原事务规则完成或恢复，录音仍有优先权。

换网仍使用设备管理凭据认证。试连成功后恢复 Wi-Fi 和续传，失败时恢复原配置。候选试连完成后恢复配置蓝牙，供 Agent 读取结果。用户关闭蓝牙后恢复正常联网和上传，普通空闲时不重开窗口。

验收覆盖普通空闲期间不因蓝牙调度断开 Wi-Fi、其他页面长按不启动配置、在配置页完成实际换网、手动关闭后恢复联网，以及录音抢占。
